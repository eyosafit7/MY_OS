# Liqlaqo OS

A web-based operating system interface built with HTML, CSS, and JavaScript.

## 🚀 Features

- 🖥️ Windows-like desktop interface
- 🧮 Calculator
- 📝 Notebook
- 🌤️ Weather app
- 🖱️ Draggable windows
- 📱 Responsive interface

## 🛠️ Built With

- HTML
- CSS
- JavaScript
